# template-engine

This repository is an unmodified GitHub fork of [accordproject/template-engine](https://github.com/accordproject/template-engine), the Accord Project's template engine that converts TemplateMark + JSON data into AgreementMark. It contains no original commits or changes on top of the upstream project — it was forked for exploring the repository, not as an independent project.
